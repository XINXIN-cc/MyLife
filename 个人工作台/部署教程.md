# 个人工作台 · 上线部署教程（Cloudflare Pages + 果创云 YesApi）

> 目标：让手机/电脑在国内**不用开梯子**就能打开网站、注册、登录、云同步。
> 当前你线上跑的还是旧的海外 Supabase 版（登录不了），照下面 6 步走就能换成国内方案。

---

## 总览

| 层 | 方案 | 说明 |
|----|------|------|
| 前端托管 | Cloudflare Pages | 免费、免备案、国内直连率高，替代原来打不开的 Vercel |
| 后端/数据库 | 果创云 YesApi（yesapi.cn） | 国内服务器、免费注册、8 年稳定 |
| 代码仓库 | GitHub `XINXIN-cc/MyLife` | 文件在 `个人工作台/` 子目录 |

---

## 第一步：注册果创云，拿 App Key

1. 打开 https://www.yesapi.cn/ 注册（用邮箱即可，国内站点不用梯子）
2. 登录后进入控制台 → 找到「应用管理」或「我的应用」→ 复制你的 **App Key**（一长串字符）
3. 把这串 App Key 复制好，下一步要用

---

## 第二步：把 App Key 填进配置

两种方式任选其一：

**方式 A（推荐，最省心）**：把 App Key 直接发给我（欣欣），我帮你填进 `cloud-config.js` 并帮你提交，你什么都不用动。

**方式 B（自己填）**：用编辑器打开 `个人工作台/cloud-config.js`，找到第 10 行：

```
  appKey: ''  // ← 在这里填入你的果创云 App Key
```

把单引号里填上你复制的 Key，改成：

```
  appKey: '这里粘贴你复制的那串App Key'
```

> 注意：只填 **App Key**，绝对不要填 App Secret（代码也没用到）。

---

## 第三步：在果创云建数据表

代码上传备份时会往一个叫 `WorkbenchData` 的表里写数据，需要先建好这个表：

1. 果创云控制台 → 数据存储 / 免费数据表 → 创建数据模型
2. 模型名称（model_name）填：**`WorkbenchData`**（必须一字不差，区分大小写）
3. 添加两个字段：
   - `owner` —— 类型选 字符串/String（用来区分每个用户）
   - `payload` —— 类型选 文本/Text（存放你的备份数据）
4. 保存

> 若登录或上传时报「签名错误 / 缺少签名」，说明控制台开启了强制签名。去控制台「设置」里关掉「强制签名校验」（只用 app_key 调用即可），或保持默认（免费版通常默认允许 app_key 直接调用）。

## 第五步：Cloudflare Pages 部署

1. 打开 https://pages.cloudflare.com → 用 **GitHub** 账号登录并授权
2. 点「Create a project」→「Connect to Git」→ 选中仓库 `XINXIN-cc/MyLife`
3. 配置项这样填：
   - **Framework preset**：选 `None`
   - **Build command**：**留空**
   - **Output directory**：**留空**
   - **Root directory（最关键）**：填 `个人工作台`（注意不是根目录，否则找不到 index.html）
4. 点「Deploy」，等 1~2 分钟
5. 部署完成后会得到一个域名，形如 `https://xxx.pages.dev`

> 以后每次你 `git push`，Cloudflare 会自动重新部署，不用再来点。

---

## 第六步：手机测试（不用梯子）

1. 手机浏览器（Safari / Chrome）直接打开你拿到的 `https://xxx.pages.dev`
2. 点「创建我的工作台」，填邮箱 + 密码（至少 6 位）
3. 正常情况：按钮变成「⏳ 注册中…」转圈，几秒后直接进入工作台
4. 进入后点 ☁️ 上传备份 / 下载备份 也能正常用

## 常见问题排查

| 现象 | 原因 / 解决 |
|------|------|
| 页面打不开 / 404 | Root directory 没填 `个人工作台`，回去改了重新部署 |
| 登录提示「App Key 错误」 | Key 复制不完整、多了空格，或填错位置 |
| 上传提示「model 不存在」 | 第三步的表名没填 `WorkbenchData`，或字段没建 |
| 注册后没反应 / 超时 | 检查手机是否真连上了果创云；偶发可重试 |
| 想用自己域名 | Cloudflare Pages 项目里加 Custom domain（需自有域名，可不绑） |
