# 个人工作台 · 上线部署教程（Cloudflare Pages 内置后端版）

> 目标：让手机/电脑在国内**不用开梯子**就能打开网站、注册、登录、云同步。
> 后端使用 Cloudflare Pages Functions + KV，和前端同源，**免域名、免备案、不依赖任何第三方账号**。

---

## 总览

| 层 | 方案 | 说明 |
|----|------|------|
| 前端托管 | Cloudflare Pages | 免费、免备案、国内直连，替代原来打不开的 Vercel |
| 后端/数据库 | Cloudflare Pages Functions + KV | 同源 `/api/*` 接口 + KV 键值存储，密码以 SHA-256 哈希保存 |
| 代码仓库 | GitHub `XINXIN-cc/MyLife` | 静态文件在 `个人工作台/` 子目录，Functions 在仓库根 `functions/` 目录 |

> Functions 代码在 `functions/api/[[route]].js`，Cloudflare 部署时会自动识别并提供 `/api/register`、`/api/login`、`/api/upload`、`/api/download` 接口，无需任何外部 Key。

---

## 第一步：在 Cloudflare 创建并绑定 KV 存储（关键，不做会 500）

云同步的数据（用户、备份）存在 Cloudflare KV 里。要先建一个 KV 命名空间，再绑到你的 Pages 项目。

1. 打开 Cloudflare 仪表盘 → **Workers & Pages** → 左侧 **KV** → **Create a namespace**
2. 名称随便填，例如 `workbench-kv`，点创建
3. 回到 **Workers & Pages** → 选中你的 Pages 项目（即 `mylife-czz` 那个）
4. 进入 **Settings** → **Bindings**（或 **Functions** → **KV namespace bindings**）→ **Add** → **KV namespace**
5. **Variable name** 必须填：**`WORKBENCH_KV`**（代码里写死读这个变量名，拼错就读不到）
6. **KV namespace** 选刚才建的 `workbench-kv`
7. 保存

> 绑定后 Cloudflare 会提示「Redeploy your project for the binding to take effect」——也就是说，绑完要去 **Deployments** 点一次 **Retry/Redeploy** 重新部署，绑定才生效。

## 第三步：确认 Cloudflare Pages 部署配置

如果还没部署过（首次），按下面建项目；如果已经部署过（`mylife-czz.pages.dev` 已存在），跳过，直接看第四步。

1. 打开 https://pages.cloudflare.com → 用 **GitHub** 账号登录并授权
2. 点 **Create a project** → **Connect to Git** → 选中仓库 `XINXIN-cc/MyLife`
3. 配置项：
   - **Framework preset**：`None`
   - **Build command**：留空
   - **Output directory**：留空
   - **Root directory（最关键）**：填 `个人工作台`
4. 点 **Deploy**，等 1~2 分钟，拿到域名 `https://xxx.pages.dev`

> 注意：Functions 目录在**仓库根** `functions/`，Cloudflare 会自动识别；静态文件从 Root Directory `个人工作台/` 提供，两者互不干扰。

## 第四步：手机测试（不用梯子）

1. 手机浏览器直接打开 `https://xxx.pages.dev`
2. 点「创建我的工作台」，填邮箱 + 密码（至少 6 位）
3. 正常情况：按钮转圈几秒后进入工作台
4. 进入后点 ☁️ **上传当前数据** / **下载云端数据** 也能正常用
5. 换一台设备用同一邮箱登录，点下载即可恢复数据

## 常见问题排查

| 现象 | 原因 / 解决 |
|------|------|
| 页面打不开 / 404 | Root directory 没填 `个人工作台`，回去改了重新部署 |
| 注册/登录提示 500 或「Internal Error」 | **没绑定 KV**（第一步漏了），或绑定后没 Redeploy。去 Settings → Bindings 确认 `WORKBENCH_KV` 已绑定，再重部署 |
| 注册提示「该邮箱已注册」 | 邮箱之前注册过，直接点「登录」用同一邮箱+密码 |
| 上传/下载报错 `登录已失效` | token 失效，退出后重新登录即可 |
| 手机能开页面但注册一直转圈 | 网络或 Cloudflare 边缘节点偶发，重试；仍不行检查 KV 绑定 |

## 备注

- 旧版 Vercel（xin-life.vercel.app，连海外 Supabase）和果创云 YesApi 方案均已废弃，本版完全自包含。
- 密码以 SHA-256 哈希存储，KV 里不存明文；会话用随机 UUID token，无状态校验。
- 图片/视频目前仍是本机存储，不跨设备；多设备云同步是整份覆盖（无冲突合并）。
- 想用自己域名：Cloudflare Pages 项目里加 Custom domain（需自有域名，可不绑）。
